# IVR 代码与横向代码速查（MDCG 2021-14，2017/2185）

> 依据 Commission Implementing Regulation (EU) 2017/2185 Annex II + MDCG 2021-14 指南。

## 赋码核心原则

1. **主 IVR 代码选 1 个**：按 2017/2185 列表顺序，**取第一个适用**的代码。
2. **横向代码（IVS/IVT/IVP/IVD）可多个**：按实际产品组成与知识领域补全。
3. 预期用途宽泛时可能多个 IVR 适用，但**主代码仍取列表中第一个适用的**；NB 可对代码加 condition/limitation（如"仅限 PSA"）。

## 高频产品 IVR 速查（实测案例）

| 产品 | 主 IVR | 理由 |
|---|---|---|
| 心肌标志物（cTnI/NT-proBNP/ST2，心衰管理） | 0602 或 0604 | 特定疾病生理标志物监测；若含癌症用途则 0301 |
| HAV 抗体（anti-HAV/HAV-IgM） | 0503 | 传染原暴露检测（免疫学间接法） |
| H.pylori 抗体（常规诊断） | 0503 | 同上 |
| H.pylori 抗体（胃癌筛查） | 0301 | 癌症筛查（列表中先于 0503） |
| Dengue NS1 抗原 | 0503 | 传染原存在检测 |
| Dengue IgG/IgM | 0503 | 传染原暴露检测 |

## 横向代码（2017/2185 Annex III）

| 代码 | 内容 | 何时选 |
|---|---|---|
| IVS 1001 | 定标器/校准品（无赋值说明） | 含校准品 |
| IVS 1007 | 带定量/定性赋值质控品 | **套件含带赋值校准品/质控品时必选**（与主 IVR 并列） |
| IVS 1008 | 仪器/设备/系统/装置 | 注册单元含分析仪本体 |
| IVS 1010 | 软件（独立或嵌入，驱动/影响检测） | 仪器含软件且影响检测 |
| IVT 2005 | 生物技术制造（抗体/蛋白生产纯化、生物分子包被） | **免疫试剂几乎必选** |
| IVT 2006 | 化学处理制造（试剂制造、化学标记） | 含化学发光标记物偶联时选 |
| IVT 2007 | 仪器制造 | 含仪器 |
| IVP 3007 | 免疫分析方法学（immunoassays） | **CLIA/免疫分析试剂必选** |
| IVP 3002 | 分子生物学方法学 | NAT/分子检测 |
| IVP 3004 | 微生物学方法学 | 细菌培养/鉴定 |
| IVD 4008 | 免疫学 | 抗原/抗体检测 |
| IVD 4012 | 病毒学 | 病毒相关产品验证 |
| IVD 4001 | 细菌学 | 细菌相关产品验证 |

## 常用代码组合模板（CLIA 免疫试剂）

```
主 IVR：按产品类型（传染原→0503；癌症→0301；特定疾病标志物→0602 等）
IVS 1007（含赋值质控品时）
IVT 2005 + IVT 2006（生物技术+化学处理制造）
IVP 3007（免疫分析）
IVD 4008 +（病毒学 4012 / 细菌学 4001 按靶标）
```
