# IVDR 分类规则速查（MDCG 2020-16 rev.5，2026-09）

> 依据 IVDR (EU) 2017/746 Annex VIII 分类规则 + MDCG 2020-16 rev.5 指南。仅作分析参考，最终分类以公告机构（NB）评估为准。

## 分类层级总览

| 类别 | 风险 | 典型产品 |
|---|---|---|
| Class A | 低 | 通用实验室仪器（Rule 5b）、标本容器 |
| Class B | 中低 | Rule 6 兜底：多数常规抗体检测、非危及生命疾病标志物 |
| Class C | 中高 | Rule 3：传染原检测（血/脑脊液）、疾病分期、危及生命疾病管理、癌症筛查、伴随诊断、遗传检测 |
| Class D | 高 | Rule 1/2：献血筛查、高传播风险传染原、血型定型 |

## 判定流程（核心决策树）

1. **先看预期用途声明**（标签/IFU）——分类完全基于预期用途，不是技术本身。
2. **检查 Rule 1（Class D）**：是否用于献血/器官捐献筛查（协调清单病原体：HIV、HBV、HCV、HTLV 等）？→ 是则 Class D。
3. **检查 Rule 2（Class D）**：血型定型（ABO/Rh 等）→ Class D。
4. **检查 Rule 3（Class C）**：逐条核对 (a)-(m)：
   - 3(a) 性传播传染原检测
   - 3(b) 血液/脑脊液标本中传染原（本身或组分）检测 —— **注意：明确排除抗体检测**
   - 3(c) 其他传染原检测（无高传播风险）
   - 3(d) 孕妇免疫状态筛查
   - 3(e) 感染性疾病状态/免疫状态判定
   - 3(f) 伴随诊断
   - 3(g) 疾病分期
   - 3(h) 癌症筛查/诊断/分期
   - 3(i) 人类遗传检测
   - 3(j) 监测分析物用于调整患者管理（错误结果危及生命）
   - 3(k) 已确诊危及生命疾病/病症患者的设备
   - 3(l) 胚胎/胎儿常规筛查
   - 3(m) 新生儿筛查
5. **检查 Rule 4**：自测（4a）→ 默认 Class C；近患者检测（4b）→ 按预期用途定类。
6. **检查 Rule 5**：通用实验室产品（5a）→ Class A；IVD 专用仪器（5b）→ Class A；标本容器（5c）→ Class A。
7. **都不适用 → Rule 6 → Class B**。

## 关键判定要点

- **抗体 vs 抗原/核酸是分类分水岭**：检测传染原本身（抗原/NAT）→ Rule 3(b)/(c) → Class C；检测抗体（暴露/免疫状态）→ 通常 Rule 6 → Class B。
- **预期用途声明直接改变分类**：同一分析物，常规诊断 vs 筛查（如 H.pylori IgG 胃癌筛查）会从 B 升到 C。
- **多规则命中取最高类**：Rule 3 任一命中即 Class C；同时命中 Rule 1 则 Class D。
- **"辅助诊断"声明不自动降类**：分类看产品类型与预期用途，与"aid in diagnosis"措辞无关。
